## 🧩 Featured Projects

### [💳 Card Transactions Kafka Demo](https://github.com/ISC-Ignacio-Naranjo/card-transactions-kafka-demo)

**Java 21 • Spring Boot • Apache Kafka • PostgreSQL • Docker • Testcontainers • GitHub Actions**

Event-driven microservices demo where transaction events are published through Kafka and consumed by a fraud-analysis service. Built to demonstrate distributed backend design, asynchronous processing, persistence, integration testing, and CI workflows.

### [🧠 3D Object Detection with SUN RGB-D](https://github.com/ISC-Ignacio-Naranjo/3d-object-detection-sunrgbd)

**Python • PyTorch • VoteNet • Computer Vision • Deep Learning**

3D object detection project using the SUN RGB-D indoor-scene dataset and point-cloud data. Includes preprocessing, training, inference, visualization, and quantitative model evaluation.

### [🤖 Java + OpenAI Integration](https://github.com/ISC-Ignacio-Naranjo/java-openai-integration)

**Java • Spring Boot • REST APIs • OpenAI API • Generative AI**

Backend project demonstrating how Generative AI capabilities can be integrated into Java applications through REST APIs while keeping AI-specific logic separated from application interfaces.

### 🌱 Lemon App — Agricultural Workforce & Harvest Management Platform

**Java • Spring Boot • PostgreSQL • REST APIs • Clean/Hexagonal Architecture • Offline-First**

Independent technical project designed to manage parcels, workers, daily harvest records, box counts, and payment calculations in real agricultural operations.

The platform is being designed with an **offline-first mobile workflow** for rural environments with unreliable connectivity and as a **structured data foundation for future analytics and Applied AI use cases**.

API and mobile source repositories are private.  
[Public JING Tech / Lemon App web repository](https://github.com/jing-mx/jingtech-web)
